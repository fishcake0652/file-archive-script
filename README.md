# file-archive-script
# 文件-归档-脚本

## 项目简介
这是计算机协会测评项目，包含三个核心需求的文件批量归档脚本，使用 C 语言编写。

## 需求说明
- 需求1：扫描并列出指定文件夹文件（支持按扩展名过滤）
- 需求2：批量重命名文件（防覆盖、打印确认后再操作）
- 需求3：归档与报告（自动移动文件到子文件夹、生成报告、撤销功能）

## 运行环境与编译说明
- 开发工具：Visual Studio
- 系统：Windows
- **重要提示**：在 Visual Studio 中编译时，需在【项目属性 -> 高级 -> 字符集】中，选择 **“使用多字节字符集”**，否则中文路径和文件名会出现乱码。

## 提交历史说明
本仓库通过 Git 分支与合并流程，分三次提交了三个需求对应的代码。
